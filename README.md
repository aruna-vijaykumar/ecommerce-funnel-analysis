# E-Commerce Funnel & Customer Behavior Analysis

## Overview
Analysis of customer behavior across an e-commerce platform using five interconnected tables covering user sessions, transactions, and product metadata (2019–2024).

## Key Findings
- Cart conversion rate: 63.4% | Purchase conversion rate: 42.1%
- Conversion rates consistent across all traffic sources (~26.7%)
- Men's department: $5.74M revenue vs Women's $5.09M
- 37.7% repeat buyer rate; mean monthly retention ~2.8%
- Steepest retention drop-off between 2nd and 3rd purchase

## Tools
Python (Pandas, Matplotlib, Seaborn, Numpy)
